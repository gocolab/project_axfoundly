# Project Launch Bizs - E2E Integration Test Specifications

본 문서는 프로젝트 내 모든 웹 화면, 대시보드, 인증 모달, 비즈니스 기능 및 백엔드 API를 빠짐없이 검증하기 위한 자연어 통합 테스트 명세서입니다.

---

## 1. 메인 랜드 페이지 & AI 진단 (MainPage)

- **경로**: `/` (기본 홈)
- **테스트 항목**:
  - GNB 로고 및 주요 메뉴(`홈`, `강의`, `IR 피칭`, `커뮤니티`, `대시보드`) 렌더링 확인
  - 메인 히어로 섹션 타이틀 및 핵심 서비스 소개 카드 표시
  - **AI 아키텍트 진단 서베이**:
    - 역할(Role), 기술분야(CoreTech), 단계(Stage), 팀규모(Team), 과제(Challenge) 선택
    - [진단 시작 / 결과 보기] 버튼 클릭 ➔ `/api/diagnosis` API 호출 및 Markdown 진단 리포트 출력 확인

---

## 2. 인증 & 데모 빠른 로그인 (AuthModal)

- **경로**: GNB 내 `[로그인]` 버튼 클릭
- **테스트 항목**:
  - 로그인 모달 오픈 및 header / 입력 필드(이메일, 비밀번호) 가시성 검증
  - 로그인 ➔ 회원가입 탭 전환 동작 확인
  - **데모 빠른 로그인 4종 역할 분기 검증**:
    - `수강생`: 로그인 후 GNB 프로필이 `수강생`으로 변경, 대시보드 이동 시 `StudentDashboard` 표시
    - `강사`: 로그인 후 GNB 프로필이 `강사`로 변경, 대시보드 이동 시 `InstructorDashboard` 표시
    - `투자자`: 로그인 후 GNB 프로필이 `투자자`로 변경, 대시보드 이동 시 `InvestorDashboard` 표시
    - `관리자`: 로그인 후 GNB에 `[관리자]` 메뉴 활성화, 관리자 대시보드 접근 가능
  - 로그아웃 처리 후 비로그인 상태 원복 확인

---

## 3. 강의 탐색 & 결제/수강신청 (CoursePage)

- **경로**: GNB `[강의]` 메뉴 클릭 (`currentPage = 'courses'`)
- **테스트 항목**:
  - 카테고리 필터링 (`전체`, `AI 모델링`, `비즈니스 기획`, `마케팅`, `개발`, `디자인`) 동작 및 카드 목록 필터링
  - 강의 카드 상세 클릭 (커리큘럼, 수강후기 탭 확인)
  - `[수강 신청하기]` 버튼 클릭 ➔ 수강신청/결제 모달 팝업 및 결제 완료 처리 흐름 검증

---

## 4. IR 피칭 & 스타트업 탐색 (IRPage)

- **경로**: GNB `[IR 피칭]` 메뉴 클릭 (`currentPage = 'ir'`)
- **테스트 항목**:
  - IR 스타트업 프로젝트 카드를 카테고리별로 검색/필터링
  - 스타트업 관심 등록(북마크) 토글 동작
  - 채용 중인 팀 프로젝트에 `[팀원 모집 신청]` 모달 오픈 및 신청서 제출 테스트

---

## 5. 커뮤니티 게시판 (CommunityPage)

- **경로**: GNB `[커뮤니티]` 메뉴 클릭 (`currentPage = 'community'`)
- **테스트 항목**:
  - 게시글 목록(공지, 자유게시판, Q&A 등) 조회
  - `[새 글 작성]` 버튼 클릭 ➔ 게시글 작성 모달 입력 및 작성 완료 후 게시글 목록 반영 확인

---

## 6. 역할별 대시보드 (Dashboards)

- **테스트 항목**:
  - **수강생 대시보드**: 수강 중인 강좌 카드, 학습 진도율 바, 수강증 발급 버튼 작동
  - **강사 대시보드**: 강좌 목록, 수강생 수, 정산 금액 렌더링 및 `[신규 강좌 개설]` 모달 작동
  - **투자자 대시보드**: 북마크한 IR 스타트업 목록 및 투자 제안 내역 표시
  - **관리자 대시보드**: 플랫폼 통합 통계 카드, 회원 목록 조회/권한 변경, 승인 대기 강좌 승인/반려 버튼 작동

---

## 7. 백엔드 API 헬스 & 엔드포인트 검증

- **테스트 항목**:
  - `GET /api/health` ➔ status 200 `{ status: "healthy" }`
  - `POST /api/diagnosis` ➔ 설문 응답 객체 전송 시 200 OK & 진단 리포트 반환 (API Mocking/실제 처리)
