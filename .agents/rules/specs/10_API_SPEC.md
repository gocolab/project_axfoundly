### 도입 후 운영 방식
- 자동 생성 문서를 도입한 시점부터 **상세 명세의 원본은 자동 생성 문서(코드)**다.
- 이 문서에는 **1장 API 목록과 API별 설계 의도·정책**만 유지한다.
- 자동 생성 문서를 도입하지 않는 프로젝트는 이 문서가 끝까지 원본이다.
