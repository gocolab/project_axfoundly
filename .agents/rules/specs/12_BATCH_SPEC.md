## 2. 배치 상세 명세

### BAT-002. 알림 발송 및 스팸 방지 큐 (Notification Delivery Engine)

- **목적**: 업무별 이벤트(강의, IR, 팀빌딩, 댓글)에 따른 이메일/인앱/알림톡 발송 및 5분 단위 스마트 묶음(Roll-up), 야간 방해금지 시간대 발송 제어
- **실행 주기**: 실시간 비동기 큐 처리 + 매일 08:30 야간 보류 해제 일괄 발송
- **실행 시간대 기준**: Asia/Seoul
- **상태**: ✅ 완료

#### 처리 내용

1. 이벤트 발생 시 `NotificationService.sendNotification()` 호출
2. 사용자별 알림 수신 설정(`NotificationPreference`) 검증 (카테고리별 채널 On/Off 및 30일 Snooze 여부 확인)
3. 5분 이내 동일 게시글 댓글/투표인 경우 기존 알림에 묶음(Roll-up) 처리 (`aggregationKey`)
4. 야간 방해금지 시간(21:00 ~ 08:00) 여부 확인:
   - 인앱 알림은 즉시 기록하되, 외부 이메일/알림톡은 `held_quiet_hours` 상태로 보류
5. 템플릿 치환 및 호기심 유발 후킹 문구 + 스마트 딥링크 CTA + RFC 8058 1-Click 수신 거부 푸터가 포함된 반응형 HTML 이메일 렌더링
6. `notificationLogs` 컬렉션에 발송 이력 기록

#### 대상 데이터

| 입력 | 출력 | 예상 건수 |
|---|---|---|
| `NotificationPreference`, `NotificationTemplate`, 비즈니스 이벤트 | `Notification`, `NotificationLog`, 이메일/알림톡 발송 | 일 500~2,000건 |

#### 실패 / 예외 처리

- **재시도**: 지수 백오프 (1분, 5분, 15분 총 3회)
- **부분 실패 시**: 실패한 채널만 `failed` 로깅 후 정상 채널 계속 진행
- **중복 실행 방지**: `aggregationKey` 및 5분 윈도우 캐시
- **알림**: 연속 5회 이상 발송 실패 시 관리자 시스템 알림

### BAT-004. 주간 인기 다이제스트 발송 (Weekly Startup Digest)

- **목적**: 주간 가장 많은 투자자 북마크 및 공감을 받은 스타트업 TOP 3 및 인기 토론글을 큐레이션하여 플랫폼 재방문(Retention) 유도
- **실행 주기**: 매주 월요일 09:00 (Asia/Seoul)
- **상태**: ✅ 완료

#### 처리 내용

1. 최근 7일간의 IR 프로젝트 북마크 수, 뷰수, 댓글수 집계
2. 상위 3개 스타트업 카드 요약 및 커뮤니티 베스트 글 추출
3. `WEEKLY_DIGEST` 템플릿 렌더링
4. `digest` 카테고리 수신 동의 회원 대상 순차 발송
