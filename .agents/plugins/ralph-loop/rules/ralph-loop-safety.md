# Ralph-Loop 안전 및 실행 가이드라인

## 개요
Ralph-Loop는 에이전트가 지정된 완료 조건(빌드 성공, 테스트 통과 등)을 달성할 때까지 반복적으로 수정-검증-개선을 수행하는 자율 루프 시스템입니다.

---

## 필수 안전 가드레일 (Safety Guardrails)

1. **최대 반복 횟수 제한 (Max Iterations)**:
   - 기본 권장 반복 횟수는 **5회**입니다.
   - 단일 세션에서 최대 **10회**를 초과하지 않습니다.
   - 횟수 초과 시 즉시 루프를 중단하고 발생한 문제와 시도 이력을 사용자에게 보고합니다.

2. **Git 상태 확인 및 보존**:
   - 루프 시작 전 미커밋 변경사항 확인
   - 각 반복 사이클마다 유의미한 진전이 있으면 변경 이력을 명확히 추적

3. **파괴적 변경 방지**:
   - 기존 설정 파일(`.env`, `package.json`의 중요 스크립트 등) 임의 삭제 금지
   - 테스트 통과를 위해 테스트 코드 자체를 무단으로 삭제하거나 완화하지 않음

4. **검증 기준의 명확성 (Verification Standards)**:
   - 프로젝트 표준 검증 명령:
     * 빌드 검증: `npm run build`
     * 타입 검증: `npm run lint` (`tsc --noEmit`)
     * E2E 검증: `npm run test:e2e`
